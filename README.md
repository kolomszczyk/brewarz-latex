# Brewiarz LaTeX

Projekt przygotowany dla mojej wspólnoty. Zawiera przykładowy skład nieszporów w LaTeX; teksty mają charakter przykładowy.

Makra, środowiska i logika składu znajdują się w `brewiarz.sty`, a `main.tex`
zawiera układ konkretnego nabożeństwa. Dokument można skompilować LuaLaTeX-em:

```bash
lualatex main.tex
```

Wymagane są fonty Liberation Serif i Noto Serif.
